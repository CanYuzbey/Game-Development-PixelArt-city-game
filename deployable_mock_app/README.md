# Map Generator Mock App

Open `MapGeneratorMockApp.html` directly in a browser, or run
`Open_MapGeneratorMockApp.bat` on Windows.

Use it for pre-Unity mock tests:

- generate deterministic maps by seed, profile, coast, and size,
- inspect land, sea, highways, roads, bridges, turns, buildings, districts, and
  encounter metadata,
- drag and drop a `deployable_city_map.v2` JSON export onto the viewer,
- pan with drag, zoom with mouse wheel, press `F` to fit, `R` to reset, and
  `Space` to generate a new seed.

This mock app is schematic. It validates layout and gameplay data before final
Unity sprite rendering is implemented.
