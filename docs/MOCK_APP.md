# Deployable Mock App

The deployable pre-Unity map generator mock app is here:

```text
deployable_mock_app/MapGeneratorMockApp.html
```

Open it directly in a browser, or run:

```text
deployable_mock_app/Open_MapGeneratorMockApp.bat
```

Use it before final Unity implementation to inspect:

- land and sea placement,
- highways and connector roads,
- bridges, turns, and intersections,
- zoning, parks, lots, buildings, landmarks, spawns, districts, and encounters,
- generated maps by seed/profile/coast/size,
- dropped `deployable_city_map.v2` JSON exports.

The app is schematic and intentionally lightweight. It is meant for mock tests,
seed review, and design feedback before final sprite/atlas rendering lands in
Unity.
